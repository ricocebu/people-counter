# People Counter

A simple people counter app built with HTML, CSS, and JavaScript.

## Features
- Increment and save count entries
- Displays a log of previous counts
- Clean and minimal UI

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
